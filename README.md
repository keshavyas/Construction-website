# Verma Cargoways Logistics Group - Website
React (Vite) + Tailwind + shadcn/ui components, with an Express/Nodemailer backend (no database).
1. `npm run install:all`
2. `cp server/.env.example server/.env` and set the Gmail App Password in SMTP_PASS
3. Dev: `npm run dev` (http://localhost:5173)  |  Production: `npm run build && npm start` (port 5000)
Photos: edit the IMG object in client/src/App.jsx. Add more shadcn components with `npx shadcn@latest add <name>`.
